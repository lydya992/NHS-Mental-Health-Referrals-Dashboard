# NHS Mental Health Referrals Dashboard

## Overview

This project analyses 100,558 NHS mental health referrals across five North London boroughs using Power BI.

## Tools Used

* Power BI
* Power Query
* Data Cleaning
* Data Analysis
* Dashboard Design
* Healthcare Analytics

## Key Findings

* Barnet received the highest referral volume (28,992 referrals)
* Haringey received the lowest referral volume (13,559 referrals)
* 62% of referrals were classified as non-urgent
* More than 11,800 referrals required emergency intervention
* GPs accounted for 38% of all referrals

## Recommendations

* Review borough-level resource allocation
* Invest in early intervention services
* Improve GP referral pathways
* Plan staffing around seasonal demand peaks
